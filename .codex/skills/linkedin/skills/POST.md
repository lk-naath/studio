# LinkedIn Posts

Use this guide when creating or editing a LinkedIn post, post idea, carousel outline, or short-form rewrite.

## Approach

- Start with one clear idea and a useful point of view.
- Write for a professional LinkedIn audience in plain, natural language.
- Prefer a strong opening, short paragraphs, and one practical takeaway.
- Use line breaks for readability.
- Use emojis, hashtags, and calls to action sparingly and only when they fit the user's voice.
- Avoid generic motivational language, engagement bait, clickbait, and unsupported superlatives.

## Default output

Unless the user specifies otherwise, provide:

1. One polished post.
2. A short title or hook option when useful.
3. Up to five relevant hashtags, only if they add value.

If the request is ambiguous, make a reasonable assumption about audience and tone, state it briefly, and draft. Ask only when the missing choice would materially change the post.

## Editing and review

For revisions, preserve the intended message while improving clarity, structure, and specificity. Before returning a draft, check that:

- the opening earns attention without exaggeration;
- every factual claim is supported by the available source;
- the post has one coherent takeaway;
- the call to action, if present, is specific and low-pressure; and
- the wording is concise enough for LinkedIn.
