# LinkedIn

Use this skill for LinkedIn content requests.

## Routing

1. Read [Lingos knowledge](../lingos/skills/ABOUT.md) for source facts.
2. Read [skills/POST.md](skills/POST.md) for the requested content format.
3. Draft the final LinkedIn content from those sources and the user's request.

Lingos knowledge is the source of truth. Search it when the topic is not fully provided.

Create the story, hook, opinion, or framing in the final post—not in the Lingos source files.

Never present invented statistics, results, quotes, credentials, dates, or capabilities as real. Preserve the user's intended message and voice.
